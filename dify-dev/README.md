# dify-dev (Antigravity plugin)

Dify API dev plugin for Agents Store. Complete coverage of the Dify App Service API (chat, completion, workflows, conversations, files, audio, annotations) and the Knowledge Base / Datasets API — auth, endpoints, streaming events, curl examples, and troubleshooting.

## Install

Workspace-scoped:
```bash
agy plugin install ./dify-dev
```
Copies this directory to `.agents/plugins/dify-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./dify-dev
```
Copies this directory to `~/.gemini/config/plugins/dify-dev/` instead.

## Workflows (UNVERIFIED)

The `workflows/*.md` directory convention is **not confirmed by official Antigravity documentation** as of 2026-08-17. If workflows aren't picked up automatically after install, paste their content manually via the editor's "+ Workspace" button.
