# sqlalchemy-dev (Antigravity plugin)

SQLAlchemy dev plugin for Agents Store. Typed SQLAlchemy 2.0 style (Mapped, mapped_column, select) with a SQLAlchemy 2.1 section: model definition patterns, relationship mapping, query optimization, Alembic migrations, and troubleshooting.

## Install

Workspace-scoped:
```bash
agy plugin install ./sqlalchemy-dev
```
Copies this directory to `.agents/plugins/sqlalchemy-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./sqlalchemy-dev
```
Copies this directory to `~/.gemini/config/plugins/sqlalchemy-dev/` instead.
