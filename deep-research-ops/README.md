# deep-research-ops (Antigravity plugin)

Multi-step research workflow over any search MCP servers; installs web-search-dev for the tools.

## Install

Workspace-scoped:
```bash
agy plugin install ./deep-research-ops
```
Copies this directory to `.agents/plugins/deep-research-ops/` in the current workspace.

Global:
```bash
agy plugin install --global ./deep-research-ops
```
Copies this directory to `~/.gemini/config/plugins/deep-research-ops/` instead.

## Workflows (UNVERIFIED)

The `workflows/*.md` directory convention is **not confirmed by official Antigravity documentation** as of 2026-08-17. If workflows aren't picked up automatically after install, paste their content manually via the editor's "+ Workspace" button.
