# grammy-dev (Antigravity plugin)

grammY (Telegram bot framework) dev plugin for Agents Store. Covers bot core, filter queries, middleware, commands, keyboards, sessions, conversations, files, payments, deployment, scaling, and the full @grammyjs/* plugin catalog for Node.js/Deno/TypeScript bot developers.

## Install

Workspace-scoped:
```bash
agy plugin install ./grammy-dev
```
Copies this directory to `.agents/plugins/grammy-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./grammy-dev
```
Copies this directory to `~/.gemini/config/plugins/grammy-dev/` instead.
