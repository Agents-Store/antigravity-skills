# postgresql-external-dev (Antigravity plugin)

PostgreSQL schema design for external database connections. Compatible SQL patterns for NocoDB and NocoBase — table creation, column types, relations, indexes, and anti-patterns.

## Install

Workspace-scoped:
```bash
agy plugin install ./postgresql-external-dev
```
Copies this directory to `.agents/plugins/postgresql-external-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./postgresql-external-dev
```
Copies this directory to `~/.gemini/config/plugins/postgresql-external-dev/` instead.
