# directus-dev (Antigravity plugin)

Directus development plugin. Knowledge base for working with Directus MCP tools (12 tools), REST API, and @directus/sdk. Covers collections, items, fields, relations, files, flows, operations, and schema design.

## Install

Workspace-scoped:
```bash
agy plugin install ./directus-dev
```
Copies this directory to `.agents/plugins/directus-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./directus-dev
```
Copies this directory to `~/.gemini/config/plugins/directus-dev/` instead.

## Workflows (UNVERIFIED)

The `workflows/*.md` directory convention is **not confirmed by official Antigravity documentation** as of 2026-08-17. If workflows aren't picked up automatically after install, paste their content manually via the editor's "+ Workspace" button.
