# nextjs-dev (Antigravity plugin)

Next.js development plugin. Knowledge base for building modern Next.js 16 applications with App Router, Server/Client Components, data fetching, Cache Components, performance optimization, and the next-devtools-mcp toolchain.

## Install

Workspace-scoped:
```bash
agy plugin install ./nextjs-dev
```
Copies this directory to `.agents/plugins/nextjs-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./nextjs-dev
```
Copies this directory to `~/.gemini/config/plugins/nextjs-dev/` instead.
