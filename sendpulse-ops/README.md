# sendpulse-ops (Antigravity plugin)

Sendpulse multi-channel marketing plugin. Manage chatbots (Telegram, WhatsApp, Instagram, Messenger, Viber, TikTok), CRM (contacts, deals, pipelines, boards, tasks), Courses (LMS) academies, courses and students, email campaigns, templates, addressbooks, and SMTP transactional email via 147 MCP tools.

## Install

Workspace-scoped:
```bash
agy plugin install ./sendpulse-ops
```
Copies this directory to `.agents/plugins/sendpulse-ops/` in the current workspace.

Global:
```bash
agy plugin install --global ./sendpulse-ops
```
Copies this directory to `~/.gemini/config/plugins/sendpulse-ops/` instead.
