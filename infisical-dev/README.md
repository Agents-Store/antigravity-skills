# infisical-dev (Antigravity plugin)

Infisical CLI dev plugin for Agents Store. Complete command-line coverage for secrets management — install & auth, infisical run/secrets/export, dynamic secrets, secret scanning with pre-commit hooks, machine-identity CI/CD auth, self-hosted, and troubleshooting.

## Install

Workspace-scoped:
```bash
agy plugin install ./infisical-dev
```
Copies this directory to `.agents/plugins/infisical-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./infisical-dev
```
Copies this directory to `~/.gemini/config/plugins/infisical-dev/` instead.
