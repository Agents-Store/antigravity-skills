# image-search-dev (Antigravity plugin)

Stock image and video search developer toolkit. MCP tool patterns for Pexels (9 tools) and Unsplash (4 tools) from mcpware-dev-tools. Photo search, video search, collections, curated content, and MinIO upload integration.

## Install

Workspace-scoped:
```bash
agy plugin install ./image-search-dev
```
Copies this directory to `.agents/plugins/image-search-dev/` in the current workspace.

Global:
```bash
agy plugin install --global ./image-search-dev
```
Copies this directory to `~/.gemini/config/plugins/image-search-dev/` instead.
