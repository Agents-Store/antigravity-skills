# teleshop (Antigravity plugin)

Teleshop store management plugin. Manage products, orders, categories, attributes, customers, webhooks, and addons for your Telegram store via 50 MCP tools.

## Install

Workspace-scoped:
```bash
agy plugin install ./teleshop
```
Copies this directory to `.agents/plugins/teleshop/` in the current workspace.

Global:
```bash
agy plugin install --global ./teleshop
```
Copies this directory to `~/.gemini/config/plugins/teleshop/` instead.
