# n8n-provision (Antigravity plugin)

n8n instance provisioning plugin. Discover workflows from the official template library (9,166+ templates), GitHub repos, and community platforms, then analyze, import, and batch-deploy them to provision an n8n instance.

## Install

Workspace-scoped:
```bash
agy plugin install ./n8n-provision
```
Copies this directory to `.agents/plugins/n8n-provision/` in the current workspace.

Global:
```bash
agy plugin install --global ./n8n-provision
```
Copies this directory to `~/.gemini/config/plugins/n8n-provision/` instead.

## Workflows (UNVERIFIED)

The `workflows/*.md` directory convention is **not confirmed by official Antigravity documentation** as of 2026-08-17. If workflows aren't picked up automatically after install, paste their content manually via the editor's "+ Workspace" button.
